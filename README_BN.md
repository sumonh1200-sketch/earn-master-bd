# Earn Master BD — প্রাথমিক ওয়েবসাইট

এটি একটি প্রাথমিক MVP/ডেমো। এতে রেজিস্ট্রেশন, লগইন, ৳২ স্বাগতম বোনাস, রেফারেল লিংক, ৩টি সফল রেফারেল না হলে উত্তোলন বন্ধ, ৳১০০ সর্বনিম্ন উত্তোলন, bKash/Nagad/Rocket নির্বাচন, কাজ জমা, অ্যাডমিন অনুমোদন ও উত্তোলন ব্যবস্থাপনা আছে।

## চালানোর নিয়ম
1. Python 3.11 বা নতুন সংস্করণ ইনস্টল করুন।
2. টার্মিনালে `pip install -r requirements.txt` চালান।
3. `SECRET_KEY` এবং `ADMIN_PASSWORD` নিরাপদ গোপন মান দিয়ে সেট করুন।
4. `python app.py` চালান।
5. ওয়েবসাইট: http://127.0.0.1:5000
6. অ্যাডমিন: http://127.0.0.1:5000/admin

ডিফল্ট অ্যাডমিন ইউজার `admin`; ডিফল্ট পাসওয়ার্ড `ChangeMe123!` — চালুর আগে অবশ্যই পরিবেশ ভেরিয়েবলে বদলাতে হবে।

## Render-এ
GitHub-এ ফাইলগুলো আপলোড করে Render-এ New Web Service → repository নির্বাচন করুন। Build command: `pip install -r requirements.txt`; Start command: `gunicorn app:app`। `SECRET_KEY`, `ADMIN_USERNAME`, `ADMIN_PASSWORD` environment variables সেট করুন। বাস্তব ব্যবহারের আগে persistent disk/managed database যুক্ত করুন; ফ্রি instance-এ local SQLite ডেটা হারাতে পারে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা ও নিরাপত্তা
- এটি পরীক্ষামূলক প্রথম সংস্করণ, বাস্তব টাকা বিতরণের জন্য প্রস্তুত নয়।
- রেফারেল এখন নতুন অ্যাকাউন্ট তৈরির সময় গণনা হয়; ৫,০০০ ব্যবহারকারীর আগে ফোন/OTP, ডিভাইস/অপব্যবহার শনাক্তকরণ ও ম্যানুয়াল যাচাই যোগ করতে হবে।
- বিজ্ঞাপন দেখে টাকা দেওয়ার ফিচার এখনো যুক্ত নয়। কেবল নীতিমালা-অনুমোদিত rewarded-ad নেটওয়ার্ক, server-side reward verification ও fraud protection যুক্ত করে চালু করতে হবে। সাধারণ বিজ্ঞাপনে ক্লিক/ভিউয়ের বিনিময়ে পুরস্কার দেওয়া যাবে না।
- পেমেন্ট এখন স্বয়ংক্রিয় নয়; অ্যাডমিন আবেদন যাচাই করে বাহ্যিকভাবে পেমেন্ট সম্পন্ন করবেন।
- বাস্তব চালুর আগে CSRF সুরক্ষা, rate limiting, email/phone verification, audit log, database backup, HTTPS এবং পেমেন্ট/বিজ্ঞাপন প্রদানকারীর শর্ত যাচাই বাধ্যতামূলক।
